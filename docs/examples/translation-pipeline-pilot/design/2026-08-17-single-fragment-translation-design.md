# Устойчивый пофрагментный перевод

## Цель

Переводить каждый текстовый фрагмент книги отдельным запросом к
TranslateGemma. Ответ проверяется и сохраняется в SQLite независимо от
остальных. Дефектный фрагмент не должен останавливать книгу.

## Поток данных

1. Выбрать из `segments` один фрагмент без актуального черновика.
2. Отправить модели только этот фрагмент и релевантную часть словаря.
3. Проверить маркер, длину, числа, протокольные имена и структуру.
4. Сохранить принятый ответ в `translation_drafts` одной транзакцией.
5. Сохранить каждую попытку в `translation_attempts`, включая модель,
   версию промпта, ответ, ошибки проверки и длительность.

## Повторы и ошибки

- Попытка 1: обычный пофрагментный перевод.
- Попытка 2: корректирующий промпт с перечнем найденных ошибок.
- Попытка 3: защита чисел и сносок маркерами с последующим восстановлением.
- После лимита фрагмент помечается `needs_review`, а цикл переходит к
  следующему фрагменту.
- Сетевые ошибки отличаются от ошибок содержания: при недоступной модели цикл
  завершается, чтобы не пометить всю книгу как дефектную.

## Ускорение

- Модель сохраняется загруженной через `keep_alive`.
- В промпт включаются только термины, найденные в этом фрагменте.
- `num_predict` ограничивается по длине одного фрагмента.
- SQLite использует короткие транзакции; один вычислительный worker не требует
  параллельных запросов к 12B-модели.

## Проверка

Автотесты покрывают: один фрагмент на группу, сохранение успешного ответа,
фиксацию неудачных попыток, переход к следующему фрагменту и восстановление числовых
маркеров.

# OAuth-книга: требования к русскому PDF и вёрстке

Дата фиксации: 2026-08-14.

Статус: **применено к текущему черновому PDF**.

## Текст и содержание

- Использовать только уже переведённую непрерывную часть `book.md`, не включая
  блоки с `TRANSLATION PENDING`.
- Ключи страниц и блоков нужны только для порядка текста и определения места
  иллюстраций; физическую постраничную сетку оригинала повторять не требуется.
- Числа, версии стандартов, RFC, URL, идентификаторы и код сохранять без
  искажений и проверять по оригиналу.
- Надписи внутри иллюстраций пока не переводить; использовать оригинальные
  изображения.

## Шрифт и оформление

- Основной текст набирать единым шрифтом, кеглем и межстрочным интервалом.
- Заголовки оформлять тем же семейством шрифта, меняя только размер и начертание.
- Моноширинный шрифт применять только к программному коду и протокольным
  примерам.
- Не уменьшать шрифт отдельных абзацев ради размещения на прежней странице.
- Использовать потоковую книжную вёрстку с едиными полями, отступами, списками,
  подписями и интервалами.

## Переносы и разрывы страниц

- Заголовок является неделимым блоком: перенос внутри заголовка запрещён.
- Если заголовок целиком не помещается, переносить его полностью на следующую
  страницу.
- Не оставлять заголовок внизу страницы без начала следующего текста.
- Не оставлять одиночный пункт оглавления на отдельной странице; соблюдать не
  менее четырёх строк оглавления в начале и конце страницы.
- После оглавления не создавать пустую страницу. «Вступительное слово» начинать
  с новой страницы.
- Не допускать наложений текста, висячих строк и необоснованно пустых листов.

## Итоговый файл и проверка

- Обновлять только существующий файл
  `Cloud_Native_Data_Security_with_OAuth_RU_DRAFT_pages_1-60.pdf`; не создавать
  рядом дополнительные версии PDF.
- Перед заменой проверять целостность PDF, совпадение чисел, наличие всех
  иллюстраций и отсутствие заголовков, разделённых между страницами.

Текущий результат: потоковая версия на 77 страниц, 24 оригинальные иллюстрации,
58 проверенных заголовков; разделённых между страницами заголовков нет.
